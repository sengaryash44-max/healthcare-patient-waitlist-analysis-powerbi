# healthcare-patient-waitlist-analysis-powerbi
Interactive Power BI dashboard analyzing healthcare patient wait lists, trends, specialty performance, and key KPIs using DAX, Power Query, and data visualization

Project Overview
This Power BI project analyzes healthcare patient wait list data to provide actionable insights into patient trends, specialty performance, and waiting times. The dashboard enables users to monitor KPIs, explore patient demographics, and identify areas requiring attention.
Dashboard Features

- Interactive filters and slicers
- Wait list KPI monitoring
- Monthly trend analysis
- Specialty-wise performance tracking
- Age profile analysis
- Average and Median wait list calculations
- Detailed drill-through reporting
Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization
Key Insights

- Monitored overall patient wait list trends over time
- Compared Day Case, Inpatient, and Outpatient categories
- Analyzed waiting times across different specialties
- Identified patterns based on age groups and time bands
